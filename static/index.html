      MUSE / REGISTRATION STUDIO每个步骤，都有迹可循。

      QUICK GUIDE

      开始之前

      1. 准备邮箱与资料

        填写可接收 Muse / Meta 邮件的邮箱、真实姓名与年满 18 周岁的生日。批量模式会共用填写的资料。

      2. 选择收码方式

        手动输入收到的 6 位数字，或提供独立邮箱 API。自动模式只读取发送后、带时区时间戳的最新验证码。

        [{"otp":"123456","time":"2026-11-16T00:00:00Z"}]
      3. 查看状态并导出

        “会话已验证”表示 /api/hatch/invite 返回有效 JSON 且取得 hatch_sess，不等于原生输入行为一致或其他未检测的权限。Meta FRL token 会明确标注，不会冒充 Muse access token。

      4. 中断与结果未知

        停止会等待已发出的请求返回。服务重启不会恢复或重复提交注册；历史结果与加密凭据会保留。账号创建结果未知时，请先检查邮箱。

      数据保存在本项目 data 目录，备份需同时保留数据库与 secret.key。
